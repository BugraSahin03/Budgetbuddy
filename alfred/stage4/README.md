# Alfred – Stufe 4: kontrolliertes Langzeitgedaechtnis

Seit 29.10.2026 ersetzt die dauerhafte Nutzerzustimmung mit `memory_save`
die Pflichtbestätigung für jeden Eintrag. Aktueller Ablauf:
`docs/alfred-conversational-coach-trial.md`. Der folgende Text beschreibt
den bisherigen Vorschlagsmodus, der optional weiter verfügbar bleibt.

Stufe 4 erweitert Alfred um einen festen, versionierten Kontextspeicher. Neue
Anschaffungen, Ziele, Workflows, Strategien, Haushaltsangaben, Praeferenzen und
Entscheidungen werden erst nach einer separaten ausdruecklichen
Nutzerbestaetigung dauerhaft uebernommen.
